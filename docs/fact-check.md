# Fact-check record

Every person, place, date and sentence of chapter text in the guide was checked in October 2026 against the full text of the sources named below. This file records the outcome of each check, what was changed and the passage relied on. Historic England and the CWGC block automated reading, so Historic England list entries were read on britishlistedbuildings.co.uk, which reproduces them, and war-grave figures were taken from Wikipedia, the Brookwood Cemetery Society and the ABMC.
